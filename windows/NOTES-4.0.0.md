## MyVerse 4.0 : un vrai logiciel Windows

MyVerse est maintenant un **programme Windows natif** (plus de page web, plus de WebView2, plus de module « bridge »). Mêmes fonctions que la 3.x, même interface « Studio ».

**À installer :**
- **PC :** `MyVerse-Setup-4.0.0.exe` (Windows 10 ou 11, 64 bits). Il remplace la 3.x au même endroit, sans rien désinstaller. Ou le dossier portable `MyVerse-4.0.0-Windows.zip`.
- **Téléphone :** `MyVerse.apk` (rien ne change pour l'app : même jumelage).

**Vos données sont reprises toutes seules** au premier démarrage : chants, recueils, réglages, Bibles importées, versets découpés, réglages OBS et téléphones jumelés (rien à rescanner).

**Nouveau dans la 4.0 :**
- Démarrage rapide, un seul programme `MyVerse.exe`.
- Fenêtre de projection native sur l'écran choisi (avec le vrai nom de l'écran), texte à la plus grande taille possible, lignes équilibrées, fondu entre les diapositives. Double-clic ou F11 : plein écran ↔ fenêtre.
- Barre du haut adaptée aux petits écrans (1024 px).
- Pare-feu : l'installateur pose les règles pour le téléphone ; MyVerse vérifie au démarrage qu'elles sont là.

**Toujours là :** recherche floue dans toutes les Bibles (même en kirundi, même mal écrit), versets bilingues, chants rangés tout seuls, ✂ Découper, imports (VideoPsalm, OpenLyrics, OpenSong, ChordPro, SongSelect, ProPresenter 6, PDF, texte, site web), OBS, télécommande Android.

Windows peut afficher « Windows a protégé votre ordinateur » (logiciel non signé) : Informations complémentaires › Exécuter quand même.
