VERSELIGHT — Bible et chants pour la projection
Double-cliquez sur MyVerse.exe (garder resources.neu à côté). Aucune installation, fonctionne sans Internet.
Nécessite Microsoft Edge WebView2 (déjà présent sur Windows 10 à jour et Windows 11).

- « Ouvrir l'écran » (ou « Afficher ») : l'écran de projection s'ouvre tout seul en plein écran
  sur le 2e écran (projecteur, télé). S'il n'y a qu'un écran, il s'ouvre dans une fenêtre :
  double-cliquez dedans pour le plein écran.
- Bible Louis Segond 1910 : « jn 3 16 », « ps 23 », « rm 8.28 » ou des mots, puis Entrée.
- Chants : Importer (VideoPsalm, OpenLyrics, OpenSong, ChordPro, SongSelect, ProPresenter 6, texte)
  ou Nouveau. Touches 1 à 9 = strophe.
- Importer : fichiers de chants, recueil PDF de cantiques numérotés, ou lien d'un site
  (une page de chant, ou une page qui liste les chants : tout est importé).
- Les raccourcis marchent aussi depuis la fenêtre de projection (et les télécommandes de présentation).
- Raccourcis : → / Espace suivant, ← précédent, Échap retirer, / chercher.
Windows peut afficher « Windows a protégé votre ordinateur » (logiciel non signé) :
Informations complémentaires › Exécuter quand même.

NOUVEAUTÉS 3.0
- Chants : collez un chant complet, même pas arrangé : il est rangé tout seul en diapositives
  de 3 à 5 lignes (accords retirés, refrain reconnu). Bouton ✂ ou double-clic sur une strophe :
  Entrée devant une ligne = nouvelle diapositive. Un long verset se découpe pareil.
- Sous l'aperçu : le verset suivant ou le couplet suivant, en entier.
- Bouton « Bibles » : importez votre Bible (Zefania XML, OSIS, USFX, JSON, texte), même en kirundi ;
  King James incluse ; choisissez la version principale et une 2e version (versets bilingues).
- Recherche par mots dans toutes les Bibles, même mal écrits ; la version est indiquée.
- Téléphone : marche aussi quand MyVerse est fermé (connexion directe à OBS, voir plus bas),
  et détecteur des versets cités par le prédicateur.

TÉLÉCOMMANDE ANDROID (MyVerse)
- Le dossier extensions\bridge doit rester à côté de MyVerse.exe.
- Au premier lancement, Windows demande une autorisation (pare-feu) : acceptez.
  Le Wi-Fi du PC doit être en réseau « Privé ».
- Bouton « Téléphone » : un code QR s'affiche. Dans l'app, « Scanner le code QR ».
  Une seule fois : ensuite le téléphone se reconnecte tout seul (même Wi-Fi).
- Dans la même fenêtre : liste des téléphones jumelés et bouton « Révoquer ».

OBS SANS LE PC (téléphone)
- Dans MyVerse : bouton OBS > activez-le avec le port et le mot de passe WebSocket d'OBS.
- Connectez le téléphone une fois : il reçoit les réglages OBS (mot de passe chiffré), les chants et les Bibles.
- Ensuite, si MyVerse est fermé, le téléphone affiche directement dans OBS (barre du bas : « OBS direct »).
