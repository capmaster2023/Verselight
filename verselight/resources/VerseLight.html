    OBS

    Afficher allume l'œil de la source dans OBS, Retirer l'éteint. Dans OBS : Outils › Paramètres du serveur WebSocket › cocher « Activer le serveur WebSocket ».

    Télécommande Android

    Dans l’app MyVerse, touchez Scanner le code QR. Une seule fois : ensuite le téléphone se reconnecte tout seul, même si l’adresse du PC change.

    Le code n’est valable que tant que cette fenêtre est ouverte. Le téléphone et le PC doivent être sur le même Wi-Fi.
